# OrvynCRM

| Folder | What it is |
|---|---|
| [`webapp`](webapp) | The product: a multi-tenant CRM (Laravel, Inertia, Vue, Tailwind). Start with [`webapp/README.md`](webapp/README.md). |
| [`website`](website) | The public marketing website (Astro, static). See [`website/README.md`](website/README.md). |

Each folder is its own project with its own dependencies (`composer`/`npm` in `webapp`, `npm` in `website`), so run commands from inside the folder you are working on. Local setup for both on Windows with Laragon: [`webapp/docs/DEVELOPMENT.md`](webapp/docs/DEVELOPMENT.md).
